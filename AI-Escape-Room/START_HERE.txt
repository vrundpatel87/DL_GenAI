AI ESCAPE ROOM — QUICK START

1. Install Python 3.10+
2. Open a terminal in this folder.
3. Run: python -m venv .venv
4. Activate the environment:
   Windows: .venv\Scripts\Activate.ps1
   macOS/Linux: source .venv/bin/activate
5. Run: pip install -r requirements.txt
6. Copy .env.example to .env and add your Gemini API key.
   Get a key: https://aistudio.google.com/app/apikey
7. Run: streamlit run app.py
8. Run tests: pytest -q

You can run without a Gemini key; the deterministic/local fallback still works.
Read README.md for GitHub setup and complete instructions.
