# Screenshots / Demo Evidence

Capture your own screenshots after running the app; do not submit sample or fabricated evidence.

Recommended screenshots:
1. `v1_start.png` — Version 1 opening screen and first Game Master message.
2. `v1_interaction.png` — Version 1 bookshelf/desk interaction.
3. `v2_state.png` — Version 2 showing inventory and puzzle progress.
4. `v2_blocked.png` — Version 2 rejecting an administrator or secret-reveal attempt.
5. `v2_escape.png` — Version 2 successful escape.

A short 1–2 minute screen recording can show the same sequence. Add the screenshots or video to this folder and link them from README.md before submitting.
