# Demonstration Guide

Suggested 2-minute demonstration:

1. Start the app with `streamlit run app.py`.
2. Select Version 1, inspect the bookshelf and show the conversational Game Master.
3. Switch to Version 2 and restart.
4. Complete the sequence: examine bookshelf; enter `2718` in drawer; take UV lens from desk; use UV lens on painting; unlock door with key and code `0426`.
5. Before completing, test an invalid code and an administrator-impersonation request. Show that the state does not change.
6. Run `pytest -q` and show the passing test output.

Save genuine screenshots in `screenshots/` and include them in your GitHub repository.
